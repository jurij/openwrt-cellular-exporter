# Triage labels

Canonical roles map to labels with the same names:

- `needs-triage`: Maintainer evaluation required.
- `needs-info`: Waiting for additional information.
- `ready-for-agent`: Fully specified and ready for autonomous implementation.
- `ready-for-human`: Human implementation required.
- `wontfix`: Will not be implemented.

These are implementation/triage labels, not Wayfinder decision labels.
Wayfinder maps and decision tickets carry only `wayfinder:*` labels.
